# Benchmark records

`reported_summary.tsv` transcribes approximate summary values from the supplied manuscript and explicit counts from Figure 1. It does not contain recomputed results, per-dataset measurements, or confidence intervals.

See [Benchmarks](../docs/Benchmarks.md) for the design, metrics, comparator versions and limitations, and [Data and reproducibility](../docs/Data-and-reproducibility.md) for missing inputs. The example in `examples/` is synthetic demonstration data and must not be substituted for the study benchmark.

# Source provenance

`source-manifest.json` records SHA-256 checksums of the supplied files. The manuscript and presentation were used to prepare documentation, not copied into the repository.

`source-changes.patch` records the limited changes between the supplied Python code and the distributed version. Its inverse reconstructs the supplied code; retain that distinction when evaluating existing scientific results. The original files on the author's Desktop were not modified.

See [CHANGELOG](../CHANGELOG.md) for the rationale and scientific impact of the changes.

# Documentation design references

The repository uses a concise installation and usage entry point inspired by [SEEKR](https://github.com/CalabreseLab/seekr), and separates tutorial material from study reproducibility material as in [scRAPID](https://github.com/tartaglialabIIT/scRAPID).

Its Documentation, Tutorial and FAQs navigation follows the section organization of the [catRAPID documentation](https://service.tartaglialab.com/static_files/shared/documentation.html), [tutorial](https://service.tartaglialab.com/static_files/shared/tutorial.html) and [FAQs](https://service.tartaglialab.com/static_files/shared/faqs.html). The scientific content here describes K-tools, not catRAPID algorithms or web-server behavior. Text, code examples and method explanations were written specifically for the supplied K-tools implementation and manuscript.
